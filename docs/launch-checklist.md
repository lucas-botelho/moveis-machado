# Confirmações para lançamento público

| Pendência              | Ação necessária                                                                | Estado                                               |
| ---------------------- | ------------------------------------------------------------------------------ | ---------------------------------------------------- |
| Telefone/email atual   | Fornecer dados verificados e configurar BUSINESS_PHONE/BUSINESS_EMAIL          | Não fornecidos; canais omitidos                      |
| WhatsApp               | Confirmar número e autorização de uso; BUSINESS_WHATSAPP em E.164              | Omitido                                              |
| .pt                    | Confirmar titularidade e acesso DNS; delegação existente não prova propriedade | Não verificado                                       |
| Migração .com          | Autorizar alterações e definir redirects permanentes                           | Não executada                                        |
| Entidade jurídica      | Nome legal, NIF/NIPC, registo, contactos do responsável                        | Pendente                                             |
| Serviço                | Confirmar quatro serviços atuais, cobertura e opções                           | Baseado no briefing/site; confirmação final pendente |
| Fotografias/trabalhos  | Autorizar reutilização, validar agrupamentos e fichas das obras                | Apenas apresentação privada                          |
| Email                  | Conta Resend, remetente com domínio verificado, destinatário novo e API key    | Sem envio real                                       |
| Proteção de formulário | Turnstile site/secret, hostname autorizado, ação contact                       | Sem configuração real                                |
| Dados pessoais         | Identidade, prazo retenção, prestadores/contratos/transferências e direitos    | Avisos definitivos por rever                         |
| Consumidor             | Livro eletrónico e entidade RAL competente                                     | Confirmar identificação/adesão e links               |
| Horários               | Confirmar semana completa caso se pretenda publicar                            | Omitidos                                             |
| Acessibilidade         | Revisão com tecnologias de apoio e aplicabilidade legal                        | Testes automáticos não são certificação              |
| Indexação              | Origem definitiva, canonicals, noindex, robots, sitemap, Search Console        | Preview não indexável                                |
| Tracking/cookies       | Auditar aplicação e plataforma pública, reavaliar se adicionar terceiros       | Sem analítica/marketing na aplicação                 |
| Performance            | Lighthouse e dados reais em ambiente final                                     | Sem métricas inventadas                              |

CONTACT_ENABLED e LEGAL_APPROVED só podem ser ativados depois de completar informação e aviso de privacidade. Rever páginas legais de ambos os idiomas: os textos atuais explicam explicitamente esta apresentação privada. Não são textos definitivos com a identidade jurídica do responsável.

Não desbloquear publicação pública apenas alterando acesso do Site. Resolver também conteúdo, direitos, indexação e funcionamento de contactos. Nenhuma compra de domínio, modificação DNS ou migração é feita nesta tarefa.
