# Arquitetura de informação

PT é o idioma principal; `/` redireciona para `/pt`. Cada página tem equivalente EN com slug próprio. A identidade interna é usada no seletor de idioma, não uma substituição de texto no URL. São 30 URLs de conteúdo: 11 páginas base e quatro trabalhos em cada idioma.

Sem páginas locais repetidas, testemunhos, classificações, catálogo de eletrodomésticos, CMS ou área reservada. Os projetos são agrupamentos do arquivo histórico; a confirmação da identificação de cada trabalho permanece no checklist.

Percurso principal: início → serviço ou portefólio → trabalho → contactos. Contactos disponíveis vão sendo publicados apenas com dados verificados. Até lá, a localização é o caminho utilizável e o formulário explica a indisponibilidade.
